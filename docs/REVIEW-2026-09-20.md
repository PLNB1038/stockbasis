## Исправлено (8)

### P1-класс
1. **Ротации -32020 сжигали 429-бюджет** (`src/rpc.mjs`, SB10, Jev 0.88/3.64): общий счётчик
   `attempt` тратился на ротации зеркал вопреки комментарию round68 — при ≥3 зеркалах скан
   детерминированно умирал. Фикс: разделены бюджеты `retries` (честные 429/5xx, кап MAX_RETRIES)
   и `holeSkips` (ротации, свой кап); хелпер `advance()` шагает endpointIdx мимо дыр этого
   вызова. Гонка round68 (holes.add от отвечающего URL) не вернулась — сьют round68 зелёный.
   Тесты: `test/round70-rpc.test.mjs` (throttled-зеркало отвечает после ротаций; кап не размыт).
2. **Не-массивный JSON валил featured-прогон** (`scripts/featured-traders.mjs`, SB11, 0.89/3.21):
   `.sort()` вне try — error-конверт прокси → TypeError → exit 1 (дырка в фиксе round69,
   тест покрывал только fetch-rejection). Фикс: `Array.isArray` гард + skip-сообщение + exit 0.

### P2-класс
3. **Tagless-ответ Jupiter кэшировался навсегда** (`src/classify.mjs`, SB14, 0.88/3.00): пустые
   теги (лаг индексации) = вечный isStock=false → тикер невидим до рестарта. Фикс: tagless —
   предварительное решение с TTL (`TAGLESS_TTL_MS` 30с, env `CLASSIFY_TAGLESS_TTL_MS`); теговые
   и curated ответы — навсегда, no-data — на своём NULL_TTL. Тесты: `test/tag-lag.test.mjs` (3).
4. **CoinGecko 401 для дат >365д молчал** (`src/price.mjs` + `src/ingest.mjs`, SB13, 0.91/2.98;
   401 подтвержден живым запросом): древние WSOL-ноги unpriced без счётчиков. Фикс:
   `isAncientDay` — локальный ответ без сети; древние ноги идут через существующий механизм
   раскрытия (partialCash → «P&L understated») + `unpricedReason: "ancient"` на трёх сайтах;
   движения причину несут, но partialCash не получают (нет proceeds для understatement).
   Тесты: `test/round70-ingest.test.mjs` (6, включая счётчик в report).
5. **Верификатор: ошибка чтения = фантом** (`scripts/verify-open-positions.mjs`, SB12, 0.85/1.76):
   сбой RPC читался как баланс 0 → ложный «tool holds phantom». Фикс: три вида неудачного
   чтения → строка skipped + вердикт INCOMPLETE, сравнения с нулём нет (доктрина reconcile.mjs).
6. **loadFeatured без shape-гарда** (`src/server.mjs`, SB19, 0.86/1.77): объект-featured.json →
   вечный retry, precompute не вооружён; строка итерировалась по символам. Фикс: единый с
   `/api/featured` `Array.isArray`; при кривой форме — громкий флаг один раз, retry снят,
   `armPrecompute()` вызван (сервер не висит с мёртвым featured). Тесты: `test/round70.test.mjs` (3).
7. **Фантомный transfer с delta=0** (`src/ingest.mjs`, SB15, 0.87/1.42): `tailUnpriced`-ветка
   пушила delta=0 (solTail присваивался только в ценовой ветке), дублируя запись выше. Фикс:
   строка удалена; неспрайсенный хвост остаётся одной записью полного размера (ledger ничего
   не теряет).
8. **Single-endpoint trust без раскрытия** (`src/reconcile.mjs`, SB17, спорный 0.77/3.03):
   семантика «trust the answer» не тронута (дизайн-решение), добавлен аддитивный флаг
   `singleSource: true` на строках отчёта, сверканных по единственному эндпоинту (оба пути
   возврата). Тесты: `test/review-fixes.test.mjs` (4, с негативным контролем кросс-чека).

## Исправлено (7)

### P2-класс
1. **Дыра P&L древних unpriced продаж** (`src/ingest.mjs` + `src/report.mjs` + `web/app.js`
   + `src/cli.mjs`, SB27, Jev 0.84/2.97): полностью unpriced древние движения (valueUsd 0)
   съедали FIFO-лоты без единого счётчика. Фикс: `unpricedMovements` в payload + нота web
   («movements unpriced (outside the price window) — realized P&L may be incomplete») +
   строка CLI. Канал отдельный от partialCash — пин round70 «no separate counter needed»
   (partial-канал) не тронут.
2. **Мёртвый partialCash после reprice** (`src/ingest.mjs`, SB20, 0.91/2.66): recent-ветка
   applySanityGate теперь стирает partialCash/unpricedReason симметрично old-ветке —
   счётчик и нота не врут для полностью переоценённой сделки.
3. **v1-транзакции молча терялись** (`scripts/featured-traders.mjs`, SB26, 0.92/2.56):
   maxSupportedTransactionVersion 0→1 (доктрина ingest.mjs); нечитаемая сигнатура — видимый
   skip (счётчик + stderr-строка), не молчаливый null. На интеграции та же правка внесена в
   `scripts/find-demo-wallet.mjs:28` (тот же паттерн, вне зон).
4. **Фантом через пустой массив** (`scripts/verify-open-positions.mjs`, SB21, 0.87/2.50):
   пустой `value:[]` больше не читается как ноль — кросс-чек по доктрине reconcile.mjs
   (переспрос другого зеркала; подтверждённый двумя пустой = факт; иначе INCOMPLETE
   «empty answer from one mirror — not compared»). Настоящий ноль — как прежде phantom.
5. **Рассинхрон полосы и precompute** (`src/server.mjs`, SB24, 0.87/2.14): precompute-раунд
   ревалидирует featured.json перед работой — вылеченный без рестарта файл сам
   подхватывается («featured.json recovered» один раз на переходе bad→ok); флаг формы —
   только на переходе ok→bad. Пин round70 «does not retry forever» обновлён под self-heal
   (остальные ассерты сохранены).
6. **Флаги без консьюмеров** (`src/cli.mjs`, SB22, спорный 0.58/2.11): CLI печатает
   singleSource (условная колонка + строка «zeroed on ONE RPC mirror's word») и
   unpriced-строки. CSV не тронут (пин 9 колонок).
7. **Нота приписывала ancient к транзиентной недоступности** (`web/app.js`, SB23, 0.80/2.05):
   формулировки разделены по `partialCashAncient` (новое поле payload): ancient → «outside
   the 365-day price window (cannot be recovered by rescanning)», иначе старый текст
   (пин round10 сохранён).
